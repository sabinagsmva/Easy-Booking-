Project Summary

EasyBooking is a web application designed to simplify hotel reservations for both guests and staff. Guests can search for hotels by city, dates, and number of travelers, create bookings, cancel if policies allow, and leave reviews after their stay. Staff can manage hotels, rooms, blackout dates, and payment policies, while the system automatically prevents double bookings and validates dates.

During development, our team faced technical challenges with database access, including “Request Timed Out” errors and missing credentials from IT, which prevented full database testing. Despite these issues, we maintained project progress, collaboration, and version control through GitHub, ensuring a consistent and organized workflow.
